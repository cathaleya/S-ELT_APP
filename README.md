# S-ELT Mobile App (Streamlit Version)

This folder is ready to be published to Streamlit Cloud.

## How to Publish:
1.  Upload all files in this folder to a new **GitHub Repository**.
2.  Go to [share.streamlit.io](https://share.streamlit.io).
3.  Connect your GitHub and select the repository.
4.  Set the main file to `streamlit_app.py`.

## Mobile View:
The app is designed with a **Mobile-First** layout. When shared via link, it will automatically fit phone screens.

## Features:
- 5 Complete Pedagogical Modules.
- Gamified Achievement System.
- Dynamic User Profile.
- Interactive Teaching Stages.
- High-Contrast Accessibility.
